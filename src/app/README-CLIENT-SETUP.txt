MASTER TEMPLATE INSTRUCTIONS - BRANDING & COLORS

To update the colors for a new client, you only need to edit ONE file:
`src/app/globals.css`

HOW TO UPDATE:
1. Open `globals.css`
2. Look at the `:root` block at the top.
3. Change `--secondary` to the client's primary brand color (e.g., if their logo is Red, change this to the hex code for that Red). This controls all underlines, hover effects, and accents.
4. (Optional) Change `--primary` if you want the main buttons to be a different color. By default, it is almost black (`#111111`) for maximum elegance.
5. Save the file. The entire website will instantly update to the new color scheme.
